# LovePuppies Website

Landing page responsive construida con React 18, Vite, Bootstrap y Sass.

## Ejecutar

```bash
npm install
npm run dev
```

La aplicación usa el puerto `3000` por defecto. Se puede cambiar con `VITE_PORT`.

## Compilar

```bash
npm run build
```

`vite-plugin-singlefile` genera la landing en un único archivo HTML dentro de `dist`.
